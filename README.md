# Clippuccino

Clipboard history app for macOS 13+ built with Swift + AppKit.

## Run

1. Download `build/Clippuccino.app.zip` and unzip and run.
2. This build is not notarized yet. If macOS shows: `Apple could not verify “Clippuccino” is free of malware...`:
3. Open `System Settings` -> `Privacy & Security`.
4. Find the blocked app message and click `Open Anyway`.

## Build and run

1. Open `Clippuccino.xcodeproj` in Xcode 15+.
2. Select the `Clippuccino` scheme.
3. Build and run.
